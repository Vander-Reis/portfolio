## Security as a step in the flow

Security that depends on remembering to run a tool doesn't scale. Here it's a merge prerequisite: if CodeQL or the tests fail, the PR doesn't get in.

## One-way sync

GitHub is the source of truth; Azure Repos is a mirror. Nobody commits to the mirror directly — the workflow takes care of it on every push to main.
