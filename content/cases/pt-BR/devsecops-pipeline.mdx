## Segurança como etapa do fluxo

Segurança que depende de lembrar de rodar uma ferramenta não escala. Aqui ela é pré-requisito de merge: se o CodeQL ou os testes falham, o PR não entra.

## Sincronização unidirecional

O GitHub é a fonte da verdade; o Azure Repos é um espelho. Ninguém faz commit direto no espelho — o workflow cuida disso a cada push na main.
